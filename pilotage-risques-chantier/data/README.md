# Données

Le projet utilise le **BIM-AI Integrated Dataset**, disponible sur Kaggle.

1. Télécharger le fichier `bim_ai_civil_engineering_dataset.csv` depuis la page Kaggle du dataset (lien dans le README principal).
2. Le placer dans ce dossier : `data/bim_ai_civil_engineering_dataset.csv`.
3. Lancer les notebooks du dossier `notebooks/` dans l'ordre.

Le fichier n'est pas inclus dans le dépôt : il reste la propriété de son auteur et peut être téléchargé gratuitement sur Kaggle.
